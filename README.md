# PyQt5 Practice: Менеджер рецептов

Приложение для хранения и управления рецептами с возможностью добавления фотографий и генерации списка покупок.

## Запуск проекта

1. Клонируйте репозиторий или скачайте архив с проектом и распакуйте его.
2. Перейдите в папку проекта: `cd recipe_manager`
3. Создайте виртуальное окружение: `python -m venv venv`
4. Активируйте виртуальное окружение:
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`
5. Установите зависимости: `pip install -r requirements.txt`
6. Запустите приложение: `python main.py`

## Функциональность

### Основные возможности

- Добавление новых рецептов с заполнением всех полей
- Редактирование существующих рецептов (выбор из таблицы, изменение, сохранение)
- Удаление рецептов с обязательным подтверждением
- Просмотр всех рецептов в виде таблицы
- Загрузка и отображение фотографий блюд (масштабирование до 300×200)
- Генерация списка покупок из ингредиентов рецепта
- Горячие клавиши для быстрого доступа к основным функциям
- Автоматическое сохранение в базу данных SQLite

  ## Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl+N`   | Добавить новый рецепт |
| `Ctrl+E`   | Редактировать выбранный рецепт |
| `Del`      | Удалить выбранный рецепт |
| `Ctrl+L`   | Загрузить фото |
| `Ctrl+S`   | Сгенерировать список покупок |

## Устранение неполадок

### Ошибка: `ModuleNotFoundError: No module named 'PyQt5'`
```bash
pip install PyQt5
```
### Ошибка: `ModuleNotFoundError: No module named 'PIL'`
```bash
pip install Pillow
```
### Ошибка: `No module named 'database'`
Проверьте, что файл `database.py` находится в корневой папке проекта.

### Ошибка: `No module named 'ui_main'`
Проверьте, что файл `ui_main.py` находится в корневой папке проекта.

### Фото не отображается
- Убедитесь, что файл изображения существует по указанному пути
- Проверьте формат файла (поддерживаются: PNG, JPG, JPEG, BMP, GIF)
- Путь к файлу не должен содержать русские буквы
